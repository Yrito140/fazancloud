# fazancloud.ru landing page

Минималистичный лендинг для онлайн-склада в тематике вейпов, жидкостей и снюсов.

## Как скачать и запустить на ПК

1. Скачайте репозиторий или архив с файлами.
2. Убедитесь, что рядом лежат файлы `index.html` и `styles.css`.
3. Откройте `index.html` двойным кликом в браузере.

### Опционально: запуск через локальный сервер

Если хотите открыть сайт как локальный сервер (например, чтобы проверить якорные ссылки), можно использовать любой простой сервер.

**Python 3:**

```bash
python -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000/index.html`.
